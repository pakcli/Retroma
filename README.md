# Vintage Computer Theme

A tactile, retro-computing inspired theme for [Obsidian](https://obsidian.md).

**Vintage Computer** brings back the soul of classic computing, retro workstations, and early graphical user interfaces into modern note-taking. Built with tactile borders, mechanical-era typography options, and an intelligent adaptive multi-row toolbar for fluid workspace productivity.

---

## Highlights

- **Classic Computing Aesthetic**: Tactile window frames, nostalgic UI controls, and authentic retro workstation vibes.
- **Adaptive Multi-Row Toolbar**: Editing toolbars dynamically wrap across multiple rows without clipping or awkward overflow.
- **Dynamic OKLCH Color Engine**: Pick your primary accent, and the theme automatically computes harmonious vintage palettes.
- **Distraction-Free Focus**: Clean workspace layout, vintage callouts, and retro-inspired typography.
- **Style Settings & Style Manager Ready**: Deeply configurable toggles for borders, shadows, scanlines, and buttons.

---

## Installation

### Manual Installation
1. Download `manifest.json` and `theme.css`.
2. In your Obsidian vault, navigate to `.obsidian/themes/`.
3. Create a new folder named `Vintage Computer`.
4. Place `manifest.json` and `theme.css` inside that folder.
5. In Obsidian, go to **Settings > Appearance > Themes** and select **Vintage Computer**.
